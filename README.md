# Diet planner

Strumento sperimentale che compone piani alimentari settimanali indicativi a partire da una base di dati sugli alimenti (CIQUAL 2020 di ANSES, rielaborata). Tutto il calcolo avviene nel browser: i dati del profilo non vengono salvati né inviati a nessun server.

La funzione "Chiarimenti" è facoltativa: chi la usa inserisce la propria chiave API (Anthropic o OpenAI) e la richiesta parte direttamente dal suo browser verso il fornitore scelto.

I piani sono indicativi e non sostituiscono il parere di un medico o di un dietista. Avviso completo e informativa privacy: [legal.html](legal.html).

Questo repository contiene solo il sito pubblicato. Il codice che costruisce la base di dati è in un repository separato.
